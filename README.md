## 🚀 Featured Projects

### 01. 📊 Customer Churn Prediction

Predicting customer churn using supervised machine learning.

- **Models:** Logistic Regression and Random Forest
- **Tools:** Python, Pandas, Scikit-learn
- **Best recorded mean cross-validation ROC-AUC:** 0.8461
- **Recorded Logistic Regression accuracy:** 80.38%
- **Focus:** Data preprocessing, model evaluation, and predictive analytics

### 02. 💬 Twitter Entity Sentiment Analysis

An NLP classification project using a dataset of 61,121 tweets.

- **Feature extraction:** TF-IDF
- **Model:** Logistic Regression
- **Recorded accuracy:** 53.8%
- **Focus:** Text preprocessing, sentiment classification, and model improvement

### 03. 🌸 Iris Classification with PySpark

Classifying Iris flowers using a Decision Tree model.

- **Tools:** Python, PySpark
- **Recorded accuracy:** 97.78%
- **Focus:** Classification and distributed data processing

### 04. 🏠 House Price Prediction

A regression project exploring the relationship between housing features and property prices.

- **Tools:** Python, Pandas, Scikit-learn, Streamlit
- **Focus:** Regression, exploratory analysis, and prediction

### 05. 🏥 NeuroAssist AI — In Development

A research-oriented project exploring movement analysis and longitudinal monitoring for Parkinson's disease.

- Investigating measurable movement-related features
- Exploring changes across repeated observations
- Interested in data quality, evaluation, and responsible healthcare AI

**Status:** In development. Not clinically validated for diagnosis.

### 06. 🤖 Autonomous Sumo Robot — In Development

A physical robotics project focused on autonomous sumo robot behavior.

- Arduino Mega and sensor integration
- DC motor control and motor drivers
- Hardware testing and iterative debugging

**Achievement:** Participated in the 5th National Sumo Robots Championship and advanced to the knockout rounds.

### 07. 🧩 Dopa do — Assistive Learning Concept

An educational technology concept exploring interactive learning activities for children with attention-related difficulties.

- Interactive questions and learning activities
- Identifying areas that may need further practice
- Memory games, timers, and reward-based engagement
