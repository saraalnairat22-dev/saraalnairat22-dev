## 🚀 Featured Projects

### 🏡 [House Price Prediction](https://github.com/saraalnairat22-dev/house-price-prediction)

A Machine Learning project developed using Python and Jupyter Notebook to explore house price prediction.

- **Tools:** Python, Jupyter Notebook, Pandas, Scikit-learn.
- **Goal:** Explore housing data and build a model to estimate house prices.
- **Focus:** Data preprocessing, feature analysis, and Machine Learning.
- 🔗 **[View Project on GitHub](https://house-price-prediction-saraalnairat.streamlit.app/)**

### 📉 [Customer Churn Prediction](https://github.com/saraalnairat22-dev/customer-churn-prediction)

A Machine Learning project that predicts customer churn using Python, with a Streamlit application for interactive predictions.

- **Tools:** Python, Jupyter Notebook, Pandas, Scikit-learn, Streamlit.
- **Goal:** Predict whether customers are likely to leave a service.
- **Models:** Logistic Regression and Random Forest.
- **Best recorded accuracy:** 80.38% using Logistic Regression.
- **Cross-validation ROC-AUC:** 0.8461.
- 🔗 **[View Project on GitHub]((https://customer-churn-prediction-sara.streamlit.app/))**

### 💬 Twitter Entity Sentiment Analysis

An NLP project that analyzes sentiment in tweets associated with different entities.

- **Dataset:** 61,121 tweets.
- **Tools:** Python, TF-IDF, Logistic Regression.
- **Accuracy:** 53.8%.
- **Goal:** Explore text classification and sentiment analysis.

### 🌸 Iris Classification with PySpark

A classification project applying distributed data processing concepts.

- **Tools:** Python, PySpark, Decision Tree.
- **Accuracy:** 97.78%.
- **Goal:** Apply machine learning techniques using the Spark ecosystem.

### 🧠 NeuroAssist AI — In Development

An AI research and prototyping project focused on analyzing movement patterns and monitoring changes over time in people with Parkinson's disease.

- **Focus:** Movement analysis and longitudinal monitoring.
- **Goal:** Explore how AI could support healthcare professionals.
- **Status:** Prototype under development; not clinically validated for diagnosis.

### 🤖 Autonomous Sumo Robot

A hands-on robotics project involving the design and development of an autonomous sumo robot.

- **Hardware:** Arduino Mega, sensors, DC motors, and motor drivers.
- **Focus:** Sensor integration, motor control, and autonomous behavior.
- **Achievement:** Participated in the 5th National Sumo Robots Championship and advanced to the knockout rounds.

### 🦊 Dopa do — Assistive Learning Concept

An educational technology concept designed to support children who experience attention-related learning difficulties.

- **Concept:** Interactive learning activities, memory games, timers, and rewards.
- **Hardware concept:** Raspberry Pi and touchscreen.
- **Goal:** Encourage engagement and support learning activities.
